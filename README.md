# EnderMod

EnderMod is a Fabric mod for Minecraft 1.21.11 that offers a neon orange color scheme, dynamic keybinds, and over 50 legal modules including HUD elements, QoL features, and visual effects. It is designed to be strictly client-side to ensure compatibility with all legal servers.

## Installation

1. Install Fabric Loader for Minecraft 1.21.11.
2. Place the mod jar in the `mods` folder.

## Use

1. Launch Minecraft with the Fabric Loader.
2. Press Right Shift to open the ClickGUI.
3. Navigate through the tabs to enable and configure modules.
